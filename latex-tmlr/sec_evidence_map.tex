\section*{Claim--evidence map}

Every row names a file a reader can open \textbf{inside the released repository}. Earlier drafts satisfied the first half of that sentence and not the second: every \S3 row pointed into \texttt{../agent-run/} or \texttt{../../handoff/}, sibling trees on the authoring host that no clone contains, so a reader could see the path and not the data. The \S3 artifacts --- both dispersion-probe waves with their preregistrations, provenance and analyser, and the four ladder output trees --- are now vendored under \texttt{sec3\_artifacts/} (95 files, 1.8 MB), and the released scripts default to those in-repo copies, so \texttt{python sec3\_dispersion\_registered.py} and \texttt{python sec3\_\bk{}artifacts/\bk{}dispersion\_\bk{}probe\_\bk{}v2/\bk{}analyze\_\bk{}v2.py} both run in a fresh clone with no arguments. Dependencies are declared in \texttt{requirements.txt}. Where a figure is \emph{not} checkable from the released artifacts, the row says so instead of pointing at a document that merely repeats it.
