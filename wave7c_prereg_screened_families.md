# Wave 7c preregistration — family generality, third attempt, screen-selected

Status: LOCKED 2026-08-16 — screen-S tally final, committed, SHA-256 pushed as
a public Kaggle dataset BEFORE any 7c sampling. The runners carry this file's
hash in their headers.

## 1. Why a 7c exists

Wave 7 (8–9B: Llama-3.1-8B, Gemma-2-9B) and wave 7b (14–24B: Phi-4,
Mistral-Small-24B) both returned UNDERPOWERED in all arms: no non-Qwen family
tested produced 20 valid packings per rung. The registered both-underpowered
branch holds and family generality is stated unresolved in both papers.

Wave 7c changes the selection procedure, not the test. Candidates were chosen
by a disclosed competence screen (screen_s_doc.md, committed f037c34 before
screen sampling): 50 one-shot generation-0 proposal calls per candidate through
an OpenRouter free-tier alias at whatever precision the provider serves, using
the byte-identical wave-7b prompt constructor, parser and evaluator. The screen
is a SELECTION instrument only: its serving path is unattested, so screen
numbers appear nowhere as evidence; they only decided which families earn a
ladder run. Screen failure is explicitly NOT evidence a family sits below the
competence floor.

## 5. Registered predictions

Identical to wave 7 §5 verbatim, applied per family, NO POOLING, same
FAMILY-DEPENDENT split-outcome rule:

- **7c.1 PRIMARY, NOT floor-gated:** among valid rows, echo(Q2_K) −
  echo(Q4_K_M) >= 15 percentage points AND echo(Q2_K) >= 30% → HELD; gap <= 5
  points → REFUTED; otherwise INCONCLUSIVE. Power floor: < 20 valid rows at
  either rung → UNDERPOWERED.
- **7c.2 SECONDARY, floor-gated:** control floor = mean accepted steps at
  Q4_K_M >= 1.0; floor met → HELD if Q2_K mean accepted <= 0.5x Q4_K_M,
  REFUTED if >= 1.0x, else INCONCLUSIVE.
- **7c.3 must-differ decision rule** as wave 7 (>= 50% echo-under-differ =
  instruction-insensitive; <= 20% = instruction-sensitive; < 5 valid =
  UNDERPOWERED).
- **7c.4 descriptives, no bounds.**

## 6. Disconfirmation

As wave 7 §6 verbatim: all advanced families evaluable and 7c.1 REFUTED in all
→ the cliff is reported as Qwen-family-specific and §3/abstract of both papers
are qualified accordingly. Registered now: if wave 7c is ALSO underpowered in
every advanced family despite screen passage, then screen-passage at an
unattested serving precision does not predict local-ladder competence — that
mismatch is itself reportable in the companion paper's serving-path section,
and family generality is stated unresolved after three attempts with no fourth
attempt on this task.

## 9. Scope

Up to four more families, one task, one toolchain, one date. Whatever 7c
returns, no absolute band measured here transports anywhere else. The
gpt-oss-20b caveat: its native release is MXFP4; the Q2_K/Q4_K_M rungs are
community GGUF conversions, so its "parent" reference differs in kind from the
dense-model waves — its results are reported with that qualifier attached.
